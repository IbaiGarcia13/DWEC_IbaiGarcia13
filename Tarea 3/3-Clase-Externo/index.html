Enlaces externos usando una clase

  • http://google.com
  • ftp://ftp.com/my.zip
  • http://nodejs.org
  • http://internal.com/test
  • Página local (interno)
  • Información (interno)

Información

JavaScript añade la clase externo a los enlaces externos. Como en el ejemplo, http://internal.com/test queda azul.

Los enlaces internos, como «Página local», no reciben la clase.
